# 📊 Admin Analytics Dashboard

A comprehensive, responsive SaaS admin dashboard built to demonstrate data visualization, complex layout management, and modern frontend architecture.

**Live Demo:** (https://admin-analytics-dashboard-delta.vercel.app/)

## 🛠️ Tech Stack
- **Framework:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Icons & UI:** Lucide React
- **Architecture:** Component-based SaaS layout

## ✨ Key Features
- **Data Visualization:** Clean layout ready for interactive charts and business metrics.
- **Enterprise Dashboard Layout:** Professional sidebar navigation and top-bar data controls.
- **Fully Responsive:** Optimized for both desktop monitoring and mobile quick-views.
- **Modern UI:** Premium aesthetic designed for modern SaaS applications.
